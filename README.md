# SquadUp AI

AI-powered team and player matching for grassroots sports (volleyball and cricket,
Coimbatore first). Two-way marketplace + trust layer + AI layer.

- Part 1 (current): backend core only — FastAPI + PostgreSQL, no AI. See `AGENTS.md`.
- Part 2 (later): Tanglish parser, Vic, AI Matcher, drafting, translation, rules RAG,
  recommender, trust layer. Folders exist as placeholders only.

Layout: `backend/` (FastAPI app), `ml/` (parser training), `docs/` (reference + project log).
Rules for every AI session live in `AGENTS.md`.
